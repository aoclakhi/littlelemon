# Little Lemon API Project

A Django REST Framework API project with token authentication.

## Features
- Menu API
- Booking API
- CRUD Operations
- Token Authentication
- Postman Testing

## Technologies
- Python
- Django
- Django REST Framework
- SQLite
- Postman

## Endpoints

### Menu
- GET /restaurant/menu/
- POST /restaurant/menu/
- PUT /restaurant/menu/<id>
- DELETE /restaurant/menu/<id>

### Booking
- GET /restaurant/booking/

### Authentication
- POST /api-token-auth/
