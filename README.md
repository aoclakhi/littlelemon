# Little Lemon API Project

## Features
- Menu CRUD API
- Booking API
- Token Authentication
- Django REST Framework

## Endpoints

### Menu
- GET /restaurant/menu/
- POST /restaurant/menu/
- PUT /restaurant/menu/<id>
- DELETE /restaurant/menu/<id>

### Booking
- GET /restaurant/booking/

### Authentication
- POST /api-token-auth/

## Tech Stack
- Python
- Django
- Django REST Framework
- SQLite
